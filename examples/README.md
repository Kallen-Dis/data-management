# 校园生活示例题库

这是一份供课程提交和功能演示使用的简单题库，共六道题，覆盖四种题型。数据在 `simple_question_bank.json`，不含真实个人信息，不自动生成问卷、答卷或共享授权。

## 题目内容

1. **年级（单选）**：大一、大二、大三、大四、研究生、其他。
2. **年龄（数字）**：0～120 周岁，必须为整数。
3. **课外活动（多选）**：体育运动、阅读、社团活动、志愿服务、文艺活动、其他；选择 1～3 项。
4. **课外学习时长（数字）**：每天 0～24 小时，允许小数。
5. **校园生活满意度（单选）**：非常满意、比较满意、一般、不太满意、很不满意。
6. **改善校园生活的建议（文本）**：有回答时要求 2～200 字。

是否必填、题目顺序和跳转规则属于问卷实例，请在从题库选入问卷后设置，不写入公共题目内容。

## 导入到已有账号

先启动 MongoDB，并在网页中注册自己的账号。然后在项目根目录运行，将 `你的用户名` 换为实际注册的用户名：

```powershell
backend/.venv/Scripts/python.exe backend/scripts/seed_question_bank.py --database survey_db --owner '你的用户名'
```

上面的命令只读预览。确认后添加 `--apply` 真正导入：

```powershell
backend/.venv/Scripts/python.exe backend/scripts/seed_question_bank.py --database survey_db --owner '你的用户名' --apply
```

脚本默认连接 `mongodb://127.0.0.1:27017`，其他实例可通过 `--uri` 指定；通过 `--file` 可选择另一份同结构 JSON。脚本是本地数据库管理工具，使用者需要已有数据库访问权限，不提供绕过网页登录的公共 API。

导入后使用该账号登录，打开“我的题库”，可看到“校园生活示例题库”；在“题目中心”也可以找到这六道题。问卷编辑器中点击“从题库或共享题目选用”，选择“我的题库”即可复用。

## 重复运行与版本演示

- 对同一账号重复导入不会重复创建题库或 v1，也不会修改已存在的正式版本。
- 不覆盖已经改名的题库、不重置已经手动切换的固定版本；已归档题库需先在页面恢复。
- 本脚本只新增示例题目与题库条目，不修改旧问卷、旧答卷、密码或共享权限。
- 修改 JSON 不会覆盖已导入题目。需要变更内容时，在题目详情中“基于此版编辑”创建 v2，再手动更新题库固定版本。
- 可将同一个年龄 v1 放入两份问卷进行跨问卷统计；再创建 v2，验证旧问卷继续保留 v1。未收集答案前统计显示零，这是正常状态。
