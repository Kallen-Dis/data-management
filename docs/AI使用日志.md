# AI 使用日志

> 要求真实记录：工具 / 提示词 / 得到的代码 / 是否修改 / 改了什么。
> 本阶段主要使用 GitHub Copilot（VS Code 内）完成。

## 1. 项目骨架

- **提示词**："创建 FastAPI + pymongo 项目骨架，含 config/db/security 分层"
- **结果**：目录结构与基础模块
- **修改**：是。db.py 增加 `$jsonSchema` 校验器与索引初始化；config 增加 JWT 过期时间

## 2. MongoDB 集合与校验器

- **提示词**："为问卷系统的 users/surveys/responses/stats 四个集合写 jsonSchema 校验器"
- **结果**：校验器初稿只校验了必填字段
- **修改**：是。surveys 增加 status 枚举与 version 最小值约束；responses 增加 snapshot 必填

## 3. 跳转引擎

- **提示词**："用有向图实现问卷跳转，支持 DFS 环检测与死题检测"
- **结果**：给出基本 DFS 环检测，但死题检测把所有顺序边都当成有效边（等于没检测）
- **修改**：是（核心，自己设计）。引入"必然命中"判定：单选全部选项被 eq 规则覆盖时
  顺序边失效，才能正确发现被跳过的死题；simulate_flow 增加防环终止条件

## 4. 校验引擎

- **提示词**："声明式规则校验四种问卷题型"
- **结果**：按题型分别实现的校验函数
- **修改**：是。增加"只校验 visited 题目"机制（AI 版本会误报被跳过的必答题）；
  数字答案统一存字符串以校验整数形式

## 5. 统计引擎

- **提示词**："提交时用 $inc 预聚合统计数据，选项计数用数组下标"
- **结果**：生成 `$inc` 更新代码（counts 按数组下标）
- **修改**：是。MongoDB `$inc` 会把 `counts.0` 存成字符串键对象而非数组，
  读取时 KeyError —— 改为全链路字符串键字典；数字题改存 num_sum/num_count 以便 $inc

## 6. 提交接口

- **提示词**："提交答卷：快照 + 校验 + 防重复提交 + 计数更新"
- **结果**：完整接口初稿，但重复提交用先查后插（有竞态）
- **修改**：是（自己设计）。引入 respondent_key + 唯一索引做原子去重，
  并发下由数据库保证唯一性；answers 过滤为只存 visited 题目

## 7. Vue 编辑器页面

- **提示词**："Vue3 问卷编辑器三栏布局，题目拖拽排序 + 跳转规则配置 + 实时预览"
- **结果**：页面样板
- **修改**：是。自动保存改为 debounce + 携带 version 的乐观锁流程；
  预览引擎复用 jump.js 与后端语义一致的镜像；预览回退逻辑改为路径截断

## 8. 填写端页面

- **提示词**："填写页：单题一屏 + 进度条 + 客户端校验 + 提交"
- **结果**：页面样板，但"提交"按钮在未作答时也显示（体验差）
- **修改**：是。"提交"仅在当前题合法作答且无下一题时显示；进度改为
  "路径位置 / 总题数"；401 时展示"去登录"卡片并支持登录后回跳

## 9. 统计面板（ECharts）

- **提示词**："ECharts 统计面板：单选环形图+柱状图，多选柱状图，数字直方图，文本词云"
- **结果**：图表配置代码
- **修改**：是。直方图分箱改为客户端动态 10 箱；词云去掉额外插件依赖，
  用字号正比频次的标签云实现；图表实例统一注册并在卸载时 dispose

## 10. 测试用例

- **提示词**："为问卷系统写 pytest 测试：认证/问卷/跳转/校验/提交/统计"
- **结果**：基础用例骨架
- **修改**：是。补充并发提交测试（10 线程 × 100 提交计数=100）、
  双通道一致性测试、快照保留测试；conftest 增加每用例清库隔离

## 11. 文档

- **提示词**："生成数据库设计文档与 API 说明"
- **结果**：文档框架
- **修改**：是。重写"为什么用 MongoDB"的论证、快照机制图示、双通道对比表；
  测试用例表按"步骤/输入/期望输出/结果"四列补全

## 12. 回归修复与验证

- **提示词**："根据你的建议展开行动"（针对工作日志中记录的全量回归失败）
- **结果**：定位到单选字符串 `eq` 跳转规则被错误地按数值阈值校验，造成问卷创建失败及测试级联失败
- **修改**：是。按题型限定数值校验范围，新增单选字符串 `eq` 与数字 `eq` 的回归用例；定向测试 13 项通过，全量测试 61 项通过
