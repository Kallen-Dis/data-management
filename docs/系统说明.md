# 系统说明

## 第二阶段更新（2026-10-23）

系统现为 2.0：在原五个页面上增加题目中心、版本详情、题库及跨问卷统计四个页面。题目可以独立创建、共享和复用；正式版本只新增，恢复也生成新版本。已发布和已关闭问卷的题目永久锁定，需要改题时复制为新草稿。

题库固定具体版本并支持手动升级；题目共享与答卷聚合授权相互独立，其他用户的原始文本不开放。原登录、跳转、校验、填写、整卷统计继续保留。

运行、一键回归、旧库兼容与回滚详见 [第二阶段实施与验收](第二阶段实施与验收.md)。以下为第一阶段系统设计说明，涉及可改已发布题目等旧行为时以本更新为准。

## 1. 系统概述

问卷星球（SurveyGo）是一个基于 MongoDB 的在线问卷系统，功能类似"问卷星"。
注册用户可以创建问卷、通过 URL 分发问卷、查看统计结果；填写者通过分享链接作答，
系统根据题目中的跳转规则自动切换题目，并对回答做合法性校验。

系统由三部分组成：

| 组成 | 技术 | 职责 |
|------|------|------|
| 前端 | Vue 3 + Vite + Element Plus + ECharts | 问卷编辑器、填写端、统计面板 |
| 后端 | Python + FastAPI + pymongo | REST API、跳转/校验/统计引擎、认证 |
| 数据库 | MongoDB | 全部数据的唯一存储 |

## 2. 系统架构

```
┌─────────────┐   HTTP/JSON    ┌──────────────────────────┐
│  Vue3 前端   │ ─────────────▶ │  FastAPI 后端             │
│ 编辑器/填写/ │                │  ├─ routers/  (API 层)    │
│ 统计面板     │ ◀───────────── │  ├─ services/ (业务逻辑)  │
└─────────────┘                │  │   ├─ jump_engine.py    │
                               │  │   ├─ validator.py      │
                               │  │   └─ stats_service.py  │
                               │  ├─ models/   (Pydantic)  │
                               │  └─ db/       (MongoDB)   │
                               └──────────┬───────────────┘
                                          ▼
                                    ┌──────────┐
                                    │ MongoDB  │
                                    └──────────┘
```

**分层原则**："逻辑引擎"与"接口层"分离。跳转、校验、统计是三个独立纯函数模块，
可单独单元测试；接口层只做参数解析、鉴权与调用。这是测试分与后端分的保障。

## 3. 功能清单

### 3.1 用户账号
- 注册 / 登录（bcrypt 密码哈希 + JWT 令牌）
- 登录后只能查看、操作自己创建的问卷（越权返回 403）

### 3.2 问卷创建与管理
- 创建问卷（标题、说明、是否允许匿名、是否允许重复填写、截止时间）
- 问卷列表（状态、回答数、截止时间）
- 发布 / 关闭 / 重新发布（状态机：draft → published → closed → published）
- 每个问卷有唯一分享链接 `/s/{share_token}`
- 编辑已发布问卷（数据由响应快照保护，见"关键逻辑说明"）

### 3.3 三种题型
| 题型 | 支持的设置 |
|------|-----------|
| 单选题 | 选项、是否必答、按选项跳转 |
| 多选题 | 选项、必答、至少/最多选择数量、按包含选项/选中数量跳转 |
| 填空题 | 文本：字数上下限；数字：最小值/最大值/是否整数、按数值跳转 |

### 3.4 题目跳转
- 跳转规则存储在问卷文档中（数据驱动，不硬编码）
- 填写时前端即时跳转（体验），提交时服务端重新执行跳转（权威）
- 保存问卷时静态分析：环检测（拒绝循环）+ 死题检测（警告不可达题目）

### 3.5 填写问卷
- 通过链接进入，单题一屏 + 进度条
- 非匿名问卷强制登录；匿名问卷用浏览器指纹去重
- 服务端强校验：发布状态、截止时间、匿名限制、重复提交限制、答案合法性
- 多人同时填写安全（单文档原子插入 + `$inc` 原子计数）

### 3.6 统计结果
- 概览：总提交数、平均填写耗时、题目数量
- 单选题：环形图（占比）+ 柱状图（人数）
- 多选题：柱状图（每选项被选次数）
- 数字填空：平均值大卡 + 区间直方图
- 文本填空：词云 + 全量明细列表
- 统计页 O(1) 读取预聚合结果；可从每份答卷的结构快照全量重建与迁移

## 4. 环境与配置

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| MONGODB_URI | mongodb://localhost:27017 | MongoDB 连接串 |
| DB_NAME | survey_db | 数据库名（测试用 survey_db_test） |
| JWT_SECRET | dev 密钥 | JWT 签名密钥，生产必须覆盖 |
| JWT_EXPIRE_MINUTES | 10080 | 令牌有效期（分钟） |
